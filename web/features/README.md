# features/ — код страниц по контекстам

`app/` — только тонкие файлы маршрутов. Вся логика, компоненты, запросы и строки контекста лежат здесь,
у каждого своя папка, наружу — только `index.ts`. Импортировать чужую фичу можно только через её `index.ts`
(так в карточку документа встают `<DocumentGuard/>` и `<DocumentAssistant/>`).

| Папка | Владелец | Маршруты |
|---|---|---|
| `platform/` | Разработчик 2 | `/login` |
| `documents/` | Разработчик 1 | `/documents`, `/documents/[id]`, `/sources` |
| `guard/` | Разработчик 3 | `/alerts`, `/family`, `/actions/[id]`, слот `<DocumentGuard/>` |
| `assistant/` | Разработчик 2 | слот `<DocumentAssistant/>` |
