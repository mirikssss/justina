# Frontend mockup — "Mening hujjatlarim" (My Documents)

Clickable UI prototype (demo only, **not** the real portal) for the document
aggregation / monitoring / legal-protection feature, shown in an e-government
portal style. Language: Uzbek.

Three levels demonstrated:
1. **Aggregation** — all documents/contracts from different registries on one screen, with version history.
2. **Monitoring + AI** — alert on a new/changed document, AI summary, and a side chat (LLM + lex.uz RAG) scoped to the document.
3. **Legal protection** — dispute, block (pause), cancel, file a statement, or confirm an action.

## Run
Open `index.html` in a browser — it is a single, self-contained static file
(no build, no dependencies; fonts load from Google Fonts).

Demo path: landing → "1 ta yangi hujjat" → open the flagged sale contract →
AI summary + chat → "Bloklash".

> Neutral `e-davlat` placeholder branding and a "Prototip • Demo" badge are used
> deliberately so this is clearly a mockup, not the live site. Data is fabricated.
